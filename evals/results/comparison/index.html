Does more investigation improve source review?

Same model. Twelve source fixtures. All 48 recorded attempts are included. Six development cases and six held out. Agent arms repeat held-out cases twice; the single-call control runs once. These are saved live-model results.

This is a small exploratory comparison on public synthetic code. It does not establish real-world security accuracy. An incomplete review is never counted as a clean scan. Only each case’s labeled CWE is scored.

Baseline: agent with read/search tools. Context: same agent plus one instruction to inspect surrounding functions and helpers. Single: one call with all fixture source supplied up front.
